# ForeverNet CJK fonts

Static TrueType, regular weight (400), derived from Noto Sans CJK SC, TC and KR.
The full character maps are retained, including Han, Hangul, kana, Latin and Cyrillic.
Regional variants preserve the intended glyph forms for Simplified Chinese,
Traditional Chinese and Korean. Modified family names begin with ForeverNet.
